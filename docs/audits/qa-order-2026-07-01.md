## D1 — Security fixes (branch `fix/jsonld-xss-and-security-headers`)

### QA-1  XSS-001: JSON-LD escaping is correct and applied
- Read `lib/utils/json-ld.ts`. Confirm `serializeJsonLd()` neutralises `<`, `>`, `&`, U+2028, U+2029 to
  JSON-safe unicode escapes (NOT HTML-entity escaping — payload is parsed as JSON). Confirm the runtime
  replacement strings contain a real backslash (source has `"\\u003c"`, i.e. two backslashes) — a single
  backslash would make `"<"` decode to `<` and defeat the escape. Confirm no literal U+2028/U+2029
  characters sit in the source (Biome `noIrregularWhitespace`).
- Behavioural proof (allowed — pure unit test): `pnpm test lib/utils/json-ld.test.ts` → 3 passing.
  Independently confirm a `</script>` payload becomes `</script>` and that output round-trips
  (`JSON.parse(serializeJsonLd(obj))` deep-equals `obj`).
- Confirm both public pages use it: `rg -n 'serializeJsonLd\(jsonLd\)' app` → `adoptar/[petToken]/page.tsx`
  and `refugios/[orgToken]/page.tsx`. Confirm `rg -n 'JSON.stringify(jsonLd)' app` → **empty**.
- Confirm the two `biome-ignore` rationales now describe the escaping (no "controlled object" / "Next
  escapes" claims).
- **Scope guard:** confirm `app/(public)/denuncias/codigo/[code]/page.tsx` is **unchanged** and its
  `dangerouslySetInnerHTML` is the static print `<style>` (no user input). Confirm no `qrSvg` injection was
  touched. Any change to these = finding.

### QA-2  HDR-001: security headers present, no CSP by design
- Read `next.config.ts`. Confirm an async `headers()` applying to `/:path*` with: `X-Frame-Options: DENY`,
  `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`,
  `Strict-Transport-Security: max-age=63072000; includeSubDomains; preload`, and a `Permissions-Policy`.
- Confirm **no** `Content-Security-Policy` key (intentional — CSP needs nonces; tracked follow-up). Its
  presence with a naive value would be a regression risk, not an improvement.
- Optional (allowed, slow): `pnpm build` succeeds and the config is accepted. Do **not** `deploy`.
