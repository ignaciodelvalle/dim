## Method

1. **Provenance gate.** Read `lib/projections/pet-compliance.ts` in full. For each obligation type (rabies, PPP, sterilization, chip), trace how "al día" is determined — does it check the recording event's `recordedBy`/actor role/verification tier, or only the event's existence? Construct the exact self-declared-event sequence that would (or wouldn't) satisfy the check.
2. **`computeConfidence` correctness.** Read the function in full — does its output correspond to the actual evidentiary strength of the underlying events (a self-reported claim scoring the same as a vet-verified one would be the defect)?
3. **PPP breed-list resolution.** Read BOTH `lib/reference/breeds.ts` and `packages/contract/src/reference/breeds.ts` in full. Confirm dog-only enforcement (a cat/other species should never reach `ppp_breed_list`/`weight_threshold` logic), and trace the jurisdiction resolution — does a pet's `jurisdiction_province`/`locality` correctly select which jurisdiction's PPP rules apply, with an explicit "indeterminado" state when jurisdiction is unset rather than silently defaulting to one jurisdiction's rules.
4. **Rabies/chip/sterilization rules vs cited ordinances.** Read the rule constants/thresholds in `pet-compliance.ts` — for each, is the citation to a specific ordinance/law present in a comment, and does the threshold match `govt_business_rules` table rows where one exists (`rg -n "govtBusinessRules" lib`) rather than being hardcoded redundantly or divergently.
5. **k-anonymity coverage.** Read `lib/metrics/anonymity.ts` in full for the k=5 implementation. `rg -rln "anonymity|kAnonymity|K_ANON" lib/metrics lib/analytics app/gob` to enumerate every consumer, then for each, confirm the anonymity function is actually called on the returned aggregate (not just imported) BEFORE the response leaves the server.
6. **KPI numerator/denominator.** Read `lib/metrics/kpi-catalog.ts` (`KPI_CATALOG` at line 368, `KPI_CATALOG_LIST` at line 2446) — for 4-5 sampled KPIs, verify the numerator and denominator queries scope the SAME population (same jurisdiction filter, same date window, same species/status filter) — the specific "rabies 42%-vs-54%" mismatched-population class.
7. **Aggregate scoping.** For each panorama/metrics aggregate, check whether it filters by `pets.jurisdiction_province`/`locality` (the cache/curated field) or by an event payload's jurisdiction snapshot — the latter can drift from the pet's current jurisdiction if the pet moved.
8. **Division-by-zero.** `rg -n "\/ (count|total|denom)" lib/metrics lib/analytics` — for each, confirm a zero-denominator guard exists and what it returns (null/0/NaN — NaN reaching a rendered percentage is a real UI-visible bug).
9. **Exploit or mutation per finding.** For a k-anonymity gap, construct the query that returns a cell with count <5. For a provenance-gate gap, construct the self-declared event sequence that wins "al día" status.
10. **At least 3 healthy items**, each with the guard traced and verified.
11. **Triage every prior.**

## Output

Produce a JSON object (or equivalent structured notes) with these top-level keys:

- **findings**: array of `{id: "C02-n", title, severity: CRITICAL|HIGH|MED|LOW, kind: bug|security|compliance, canonRule?, path, line, evidenceCmd, evidenceOutput(≤400ch), exploitOrMutation, fix(one line), fixClass: doc-fix|code-sdd|fence-candidate|po-decision, priorId?, priorStatus?}`
- **healthy**: array of `{title, property, path, line, evidenceCmd, evidenceOutput, whatWouldBreakIt, guardedBy, guardVerified: bool}` — minimum 3
- **priorTriage**: array of `{priorId, status: closed|still-open|not-reproducible, evidence}` covering every prior
- **nits**: array of `{path, line, note}`
- **coverage**: `{filesRead: [...], areasNotReached: [...]}`

**Severity rubric**:
- CRITICAL: a k-anonymity bypass returning an identifiable individual's data to a govt client, or a provenance-gate bypass that lets a self-declared event mark a legally-consequential obligation compliant.
- HIGH: a KPI with a mismatched-population numerator/denominator presented to officials as a real number, a PPP rule misapplied to the wrong species/jurisdiction with a legal consequence.
- MED: an aggregate scoped on stale event-payload jurisdiction instead of the pet's current one with a bounded (non-PII) drift, a division-by-zero producing a cosmetic bug (NaN%).
- LOW: hygiene, a hardcoded threshold that happens to match `govt_business_rules` today but risks silent divergence later.

This brief is meant to be runnable by hand by someone who has not seen this workflow — if a step above is ambiguous without prior context, treat that as a bug in the brief and resolve it the most literal way rather than guessing at intent.
