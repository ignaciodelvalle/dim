## Contract

## Question

Should `app/` (and `lib/`) keep issuing Drizzle queries directly, or must all database access — reads included, not just writes — go through `src/modules`? The existing hexagonal-lite write-path rule is silent on reads; the codebase, `AGENTS.md:1024`, and a dependency-direction fence comment all lean on page-level reads working today. The PO's decision sets the baseline for a future `check-app-db-boundary.ts` fence and determines whether ~150 files are grandfathered or a burn-down list.

## Measurements to take

Import-surface counts (`@/db`, `drizzle-orm`) across `app/`, `lib/`, `src/`, `apps/mobile`:
```
rg -l "from ['\"]@/db" app | wc -l
rg -l "from ['\"]drizzle-orm" app | wc -l
rg -l "from ['\"]@/db" lib | wc -l
rg -l "from ['\"]drizzle-orm" lib | wc -l
rg -l "from ['\"]@/db" src | wc -l
rg -l "from ['\"]drizzle-orm" src | wc -l
rg -l "from ['\"](@/db|drizzle-orm)" apps/mobile | wc -l
rg -l "api/v1" apps/mobile/src | wc -l
```

Read/write split in `app/` (multiline-tolerant, chains span lines):
```
rg -lU --multiline '\bdb\s*(\r?\n\s*)?\.(select|execute)\(' app | wc -l
rg -lU --multiline '\bdb\s*(\r?\n\s*)?\.(insert|update|delete|transaction)\(' app | wc -l
comm -23 <(read-files sorted, excl tests) <(write-files sorted) | wc -l
for p in select insert update delete transaction execute; do rg -lU --multiline "\bdb\s*(\r?\n\s*)?\.$p\(" app | wc -l; done
```

Route-shape classification (must NOT assume route conventions — 12 db-touching files are neither `page.tsx` nor `route.ts` nor `layout.tsx`):
```
rg -lU --multiline '<op-re>' app -g "page.tsx" | wc -l
rg -lU --multiline '<op-re>' app -g "*.tsx" -g "!page.tsx" | rg -v "test\.|__tests__"
rg -lU --multiline '<op-re>' app -g "layout.tsx" | wc -l
rg -lU --multiline '<write-re>' app -g "route.ts" | rg cron | wc -l
```

Spine-write census (the highest-stakes single number):
```
rg -lU --multiline '\.(insert)\(\s*(\r?\n\s*)?petEvents' app
rg -oU --multiline '\bdb\s*(\r?\n\s*)?\.(insert|update)\(\s*(\r?\n\s*)?([A-Za-z]+)' app -N | rg -o '[A-Za-z]+$' | sort -u | wc -l
```

Read-tier adoption (does the page already call a named helper alongside its inline select):
