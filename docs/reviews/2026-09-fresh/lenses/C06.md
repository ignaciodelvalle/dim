## Refuted

**C06-2 — "deploy:staging's migration step targets the LOCAL database"**: finder claimed `migrate.ts`'s dotenv loading of `.env.local` would silently override an intended remote `DATABASE_URL`, migrating the developer's own machine while the code ships to production. Refuter reason: the dotenv facts reproduce, but dotenv does not override an already-set variable, and the repo's only documented invocation (`docs/ops/staging-deploy.md:16-22`) sets `$env:DATABASE_URL` to the staging pooler URL *before* running `pnpm deploy:staging` — under that procedure `migrate.ts` targets staging and prints `[REMOTO]`. The finder also mis-timed the mitigation: the `Destino` banner prints when `migrate.ts` starts, i.e. *after* the ~20-minute `verify` has already finished, so it's the freshest thing on screen, not something that scrolls past. What survives is only that nothing mechanically refuses a local target — at most LOW given the loud banner and documented step, which the refuter voted as not warranting a standalone finding.

**C06-3 — "Password-reset e-mail builds its redirect with `??`, the exact empty-string trap `lib/infra/site-url.ts` exists to cure"**: finder claimed a bare `??` in `recoveryRedirectTo()` would produce a host-less relative URL if `NEXT_PUBLIC_SITE_URL` were set to empty string. Refuter reason: the code diff reproduces exactly, but the claimed failure is prevented on every environment where it would matter, by code the finder read only halfway. `lib/infra/env.ts:49-53`'s `isRealProdDeploy()` classifies staging and production both as "real prod" (production NODE_ENV + non-local DATABASE_URL), and `:70-75` then requires `NEXT_PUBLIC_SITE_URL` via `.min(1).url()` — an empty string fails validation. `instrumentation.ts:17-29` imports this env module inside `register()`, so validation throws at boot on every Node server instance before any request is served, and the parse is eager at module load (`env.ts:125`). The finder's stated escape hatch ("a preview/staging build whose DATABASE_URL still points local") describes a deploy that cannot reach its database at all. Residual is a convention breach (inconsistent style vs. `lib/infra/site-url.ts`), not a defect path.
